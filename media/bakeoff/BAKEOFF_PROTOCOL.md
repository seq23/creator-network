# Renderer Bake-off Protocol

Use the same owner-approved canonical synthetic reference, the same ~15-second approved script, and the same approved audio across every candidate. Do not run paid candidates until explicitly enabled and budget-authorized.

Score: face consistency 25%; human realism 20%; speech realism 20%; motion 15%; social-native feel 10%; cost 10%. Any visibly fake/identity-drifting result fails regardless of aggregate score. Store candidate, settings, duration, estimated/actual cost, scores, failure notes, and artifact hash. Winning renderer is configuration, never creator identity.
