# Phase 6 Analytics

This layer ingests post-level social metrics, keeps only the latest snapshot per post, derives attention/intent rates, and aggregates by employee + experiment.

## Truth boundary
Conversion attribution is deferred. Revenue, purchases, qualified leads, and economic value are **unavailable**, not zero. Engagement is never relabeled as revenue. Missing metrics remain null at ingestion. Optimizer decisions may increase **organic production capacity** from attention + intent evidence, but paid amplification is prohibited until real economic evidence exists.
