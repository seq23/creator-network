# Creator Network — Repo Identity

**Repository:** `creator-network`
**Phase:** 1 — Control Plane Foundation
**Purpose:** Standalone control plane for four persistent virtual creator employees that acquire customers/leads for existing portfolio businesses.

## Boundaries
This repository owns employee/persona contracts, experiment governance, state contracts, budget policy, health-state definitions, and future orchestration interfaces. Existing product repositories remain the conversion systems and are not modified in Phase 1.

## Source-of-truth rule
For this delivered artifact, this full-baseline ZIP is the source of truth. Local validation, commit, and push occur through the user's governed Repo Operator/updater workflow.
