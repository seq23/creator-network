# Signup kit — the four creators' social accounts (owner-only)

Generated by `scripts/signup-kit.mjs` from `distribution/config/signup-kit.json` — edit the JSON, not this file.
Why owner-only: signup needs SMS + CAPTCHA on real hardware; automating it flags the accounts at birth (ledger named stop).

## Order
1. **threads** → 2. **instagram** → 3. **tiktok** → 4. **x** → 5. **youtube**

Threads and Instagram share one Meta login and connect to Buffer in one step; TikTok next (largest reach for short video); X is low-effort; YouTube last (Shorts are selective and need a Google account per creator).

## Rules that apply to every account
- **Use the creator's own email** (inbound routes to your inbox via Cloudflare Email Routing — verification codes arrive there). One phone number can verify several Instagram/Threads accounts; TikTok and X may ask for a distinct number per account — use your second line if prompted.
- **Bio ends with the disclosure line** `Virtual creator 🤖` on every platform (FTC 2026 AI-likeness disclosure; also required for Meta/TikTok AI-content labels).
- **Avatar** = `avatar_400.png` in the creator's references folder (the approved `face_front`, 400×400). Same image on every platform — identity lock.
- **Display name** exactly as given; **handle** first choice, fall back to the second, otherwise append `.official`. Record the handle you got in the table at the bottom.
- **Birthday**: the year given, any day — it must be consistent across platforms for the same creator.
- Skip "find contacts", skip "suggested follows", do not link to your personal accounts.

## After each creator: connect to Buffer
1. Log in to Buffer **as that creator** (their email — four separate Buffer accounts, never consolidated).
2. Channels → Connect → choose the platform → authorise with the account you just created.
3. Repeat for Threads, Instagram, TikTok, X, YouTube as available.
4. Tell me "channels connected for <name>" — I re-run `python3 scripts/vault-exec.py -- node scripts/buffer-discovery.mjs`, which records the channel ids and lifts the named stop for that creator.
